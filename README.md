# doc2qa

批量文本分块 + 阿里云百炼智能体调用工具。

递归扫描指定目录下的文本文件，按原生段落边界分块（每块 ≤2000 字符），逐块调用阿里云百炼智能体，将返回的 JSONL 结果按处理顺序写入与原文件同名的 `.jsonl` 输出文件。适用于"文档转问答对（doc → QA）"类的批量数据生产场景。

## 功能特性

- **段落分块**：按空行识别原生段落边界；连续短段落自动合并，单块严格不超过 2000 字符；超长段落自动在段内按句子边界切分（无句读时按固定长度硬切兜底）
- **强制分隔分块**：文本中出现连续 3 个及以上减号（`---`）时无条件在此处切分，该规则优先级最高，不受段落边界 / 字符数上限等其他条件影响
- **百炼智能体调用**：直接 HTTP 调用阿里云百炼智能体应用接口，appid / apikey / endpoint 等全部配置项来自 `.env`，代码零硬编码
- **稳定性保障**：请求超时控制、指数退避重试（网络异常 / HTTP 429/5xx / 返回格式非法均可重试）、全量运行日志与失败文件清单
- **返回内容校验**：智能体返回须为 JSONL（一行一个 JSON，形如 `{"prompt":"","response":""}`），逐行校验合法性后才写入输出
- **断点续跑**：同名 `.jsonl` 已存在的文件自动跳过；输出采用临时文件 + 原子改名，不会出现半截产物
- **只读输入**：原始文件与目录结构完全不被修改，输出 `.jsonl` 与原文件同目录

## 环境要求

- Python 3.8+
- 一个阿里云百炼智能体应用（用于获取 appid 与 apikey）

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 创建配置文件（复制模板并填写真实凭证）
cp .env.example .env

# 3. 运行
python main.py --input ./你的文本目录
```

不带 `--input` 参数时，使用 `.env` 中 `INPUT_DIR` 指定的目录。

## 配置说明（.env）

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `BAILIAN_APP_ID` | 百炼智能体应用 ID（必填） | — |
| `BAILIAN_API_KEY` | 百炼 API Key（必填） | — |
| `BAILIAN_ENDPOINT` | 调用地址，支持 `{app_id}` 占位符 | 百炼官方地址 |
| `BAILIAN_TIMEOUT` | 单次请求超时（秒） | `60` |
| `BAILIAN_MAX_RETRIES` | 失败重试次数 | `3` |
| `BAILIAN_RETRY_BACKOFF` | 重试退避基数（秒），指数退避 | `2` |
| `CHUNK_MAX_CHARS` | 块最大字符数 | `2000` |
| `INPUT_DIR` | 默认输入目录 | `./input` |
| `TEXT_EXTENSIONS` | 处理的扩展名（逗号分隔） | `.txt,.md` |

## 处理流程

```
扫描目录（递归，跳过已有同名 .jsonl 的文件）
  └─ 读取文件（UTF-8 优先，GBK 回退，换行符归一化）
      └─ 段落分块（≤2000 字符，超长段落段内切分）
          └─ 逐块调用百炼智能体（顺序调用，异常重试）
              └─ 返回 JSONL 逐行校验（含 prompt/response 键的合法 JSON）
                  └─ 原子写入 <原文件名>.jsonl（块序 + 行序）
```

运行结束时输出汇总：成功 / 跳过 / 空文件 / 失败数量及失败文件清单；详细日志写入 `logs/run_时间戳.log`。

## 输出格式

每个文本文件生成一个同名 `.jsonl`（如 `input/sub/a.txt` → `input/sub/a.jsonl`），每行为智能体返回内容中经校验的一行 JSON：

```json
{"prompt": "根据文本生成的问题", "response": "对应的回答"}
{"prompt": "根据文本生成的问题", "response": "对应的回答"}
```

行序 = 块处理顺序 + 块内行顺序；智能体返回对象中的多余键会原样保留。

## 项目结构

```
doc2qa/
├── main.py          # CLI 入口 + 批量处理编排
├── config.py        # .env 配置加载与校验
├── chunker.py       # 段落分块逻辑
├── bailian.py       # 百炼智能体调用客户端（重试/超时/JSONL 校验）
├── .env.example     # 配置模板（复制为 .env 使用）
├── requirements.txt # 依赖清单
└── logs/            # 运行日志（自动生成）
```

## 注意事项

- `.env` 包含 API 密钥，已被 `.gitignore` 排除，严禁提交到版本库
- 智能体需返回固定格式 `{"prompt":"","response":""}` 的 JSONL（每行一个 JSON 对象），否则该块将触发重试
- 某块重试耗尽后该文件记为失败且不产出 `.jsonl`，下次运行自动重试整个文件
